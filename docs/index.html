MindNest

A multi-agent AI conversation simulator wired to an SO-101 robot arm that plays rock-paper-scissors over a REST API. Built at Cal Hacks 12.0, Oct 24–26, 2025, San Francisco.

View on GitHub← kitrakrev.github.io
My first hardware project. Before this weekend everything I built lived on a screen. Here, an HTTP call from a laptop had to turn into a servo landing a gesture on time, on a crowded hackathon floor.

API call on the laptop → the SO-101 arm shakes, throws a gesture, and resets.

How it fits together

Chat Simulator (personas)→FastAPI robot server→RPS controller→LeRobot + Feetech servos→SO-101 arm

Robot controller (bot_code/)

  • FastAPI server with endpoints for /rock, /paper, /scissors, /random, plus /shake, /rest, /yes and /no gestures.
  • /reach_human: scans positions with OpenCV face detection and reaches toward the nearest person.
  • Drives the SO-101 through Hugging Face LeRobot (Feetech servo bus), with smoothing and shake-timing tests.

Chat Simulator (chat_simulator/)

  • Multi-persona AI conversations with dynamic persona creation and group management.
  • A global Meta-Advisor with persistent memory through Letta.
  • Real-time updates over WebSockets, SQLite storage, and TLDR summaries of conversations.
